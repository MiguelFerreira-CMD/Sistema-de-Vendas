# Sistema de Vendas

Um sistema simples de vendas desenvolvido em **Python** utilizando **Streamlit**, **Pandas** e **Plotly**.

O projeto permite cadastrar vendas, visualizar os registros e acompanhar informações através de um dashboard.

## Funcionalidades

- Cadastro de vendas
- Seleção de data, vendedor e produto
- Registro de quantidade e valor
- Validação dos dados da venda
- Armazenamento das vendas em arquivo CSV
- Visualização das vendas cadastradas
- Dashboard com:
  - Faturamento total
  - Produto mais vendido
  - Vendas por vendedor
  - Percentual de vendas por produto
  - Quantidade vendida por produto
- Gráficos interativos utilizando Plotly

## Tecnologias utilizadas

- **Python**
- **Streamlit**
- **Pandas**
- **Plotly**
- **CSV**
